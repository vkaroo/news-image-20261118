# The World Today — 18 November 2026

[![reward](https://make.fun/badge/news-image-20261118/vkaroo/news-image-20261118/reward.svg)](https://make.fun/bounty/news-image-20261118)

A one-page newspaper front page that sums up the world news of Wednesday 18 November 2026 in a single 1024×1024 image. The lead story is the US–Iran escalation in the Gulf — US jets striking a Revolutionary Guard missile site on Qeshm Island and the exchanges that followed — and five shorter stories cover the Kerch Bridge strikes, the Xi–Putin–Trump summit in Shenzhen, Mary Peltola's Senate win in Alaska, the Ebola outbreak in DR Congo, and Category 5 Cyclone Xavier in the Northern Cook Islands. Every pictogram on the page is drawn from simple shapes; there are no photos. The date is printed in large type across the front page so it can be read at a glance.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` into the `out` directory. It uses only the Node.js standard library, needs no network, and produces identical bytes on every run.
